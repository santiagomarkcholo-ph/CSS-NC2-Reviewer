Safety first
  • Unplug the PSU, press the power button to drain charge.
  • Wear an ESD wrist strap or touch bare metal case.
  • Hold boards by the edges. Keep screws sorted per part.
🔧 Disassembly order
  1. Unplug all cables and peripherals
  2. Remove side panel
  3. Disconnect power and data cables (PSU, SATA)
  4. Remove expansion cards (GPU, NIC)
  5. Remove RAM
  6. Remove drives (HDD/SSD, optical)
  7. Remove CPU fan/heatsink, then CPU
  8. Remove motherboard
  9. Remove PSU

Mnemonic: Cables, Cards, RAM, Drives, CPU, Mobo, PSU = “Can Cats Run, Dodge Cars, Maybe Panic?”

🔩 Assembly order
  1. Install PSU in the case
  2. Install standoffs, then motherboard
  3. Install CPU (match the gold triangle), thermal paste, heatsink and fan
  4. Install RAM (click both clips)
  5. Install drives (HDD/SSD, optical)
  6. Install expansion cards
  7. Connect 24-pin, 4/8-pin CPU power, SATA, front panel and USB headers
  8. Cable manage, close case, test POST

Assembly is basically the reverse of disassembly.
